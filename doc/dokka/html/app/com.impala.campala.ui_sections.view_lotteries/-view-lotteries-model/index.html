ViewLotteriesModel

class ViewLotteriesModel(val lotteryRepo: LotteryRepository, val campsiteRepo: CampsiteRepository, val reservationRepo: ReservationRepository, val entrantProfileRepo: EntrantProfileRepository, val user: User, val scope: CoroutineScope) : ObservableModel<ViewLotteriesModel>

In entrant mode this is the list of lotteries the user has joined, with status on if they've won it or not Lotteries the entrant lost, declined, or already made a reservation through, are left out, since there's nothing left for them to do there In campsite owner mode this is the list of active lotteries owned by that campsite owner

Parameters

lotteryRepo

the LotteryRepository to fetch lotteries from

campsiteRepo

the CampsiteRepository, used to get the name/location of each lottery's campsite

reservationRepo

the ReservationRepository, used in entrant mode to hide lotteries the user already reserved through

entrantProfileRepo

the EntrantProfileRepository, used in campsite owner mode to get the names of people on each waitlist

user

the signed in User, used to find their lotteries

scope

the CoroutineScope that the suspend fetches run in
