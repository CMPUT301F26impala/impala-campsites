FormCampsitesModel

class FormCampsitesModel(val repo: CampsiteRepository, val campsiteOwnerProfileRepo: CampsiteOwnerProfileRepository, val user: User, val scope: CoroutineScope, var campsite: CampsiteModel? = null) : ObservableModel<FormCampsitesModel>

Model for the create and edit version of Campsite form.

Stores information entered into the form, and notifies view about the changes. Saves campsites after creation and editing, as well as loading them to display values to the user.

Parameters

repo

CampsiteRepository consisting of all campsites

campsiteOwnerProfileRepo

Repository of campsite owner profiles. Used for saving new campsites to a user's profile

user

the authorized user editing the form

scope

the CoroutineScope used for Firebase operations

campsite

campsite whose data will be edited, passed as null in creation mode
