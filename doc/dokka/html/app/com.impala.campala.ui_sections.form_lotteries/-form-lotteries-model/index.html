FormLotteriesModel

class FormLotteriesModel(val repo: LotteryRepository, val scope: CoroutineScope, var lottery: LotteryModel? = null, val ownerId: String, val campsiteRepo: CampsiteRepository) : ObservableModel<FormLotteriesModel>

Model for the create and edit version of Lottery form.

Stores the information entered into the form, and notifies view about the changes. Saves lotteries after creation and editing, as well as loading them to display values to the user. Also gets the list of campsites to be displayed in the dropdown.

Parameters

repo

LotteryRepository consisting of the lotteries

scope

the CoroutineScope used for Firebase operations

lottery

lottery whose data will be edited, passed as null in creation mode

ownerId

the id of the campsite owner creating the lottery

campsiteRepo

Repository used to get the campsites for the dropdown
