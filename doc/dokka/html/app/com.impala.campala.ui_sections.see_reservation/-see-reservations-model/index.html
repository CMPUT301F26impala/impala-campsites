SeeReservationsModel

class SeeReservationsModel(val resDB: ReservationRepository, val campsiteDB: CampsiteRepository, val entrantDB: EntrantProfileRepository, val user: User, val scope: CoroutineScope) : ObservableModel<SeeReservationsModel>

Model for the reservations tab screen

In entrant mode this is the user's own reservations, in campsite owner mode it's the reservations made at the user's campsites

Parameters

resDB

the ReservationRepository to fetch reservations from

campsiteDB

the CampsiteRepository to fetch each reservation's campsite from

entrantDB

the EntrantProfileRepository, used in campsite owner mode to get the name of whoever made each reservation

user

the signed in User

scope

the CoroutineScope that the suspend fetches run in
