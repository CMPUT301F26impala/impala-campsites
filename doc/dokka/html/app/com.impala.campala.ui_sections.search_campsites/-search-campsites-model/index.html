SearchCampsitesModel

class SearchCampsitesModel(val repo: CampsiteRepository, val campsiteOwnerProfileRepo: CampsiteOwnerProfileRepository, val lotteryRepo: LotteryRepository, val user: User, val scope: CoroutineScope, val viewMode: SearchCampsitesViewMode) : ObservableModel<SearchCampsitesModel>

Model for the 'Browse Campsites' screen

This tracks all the filter state (the search string and the filter values) And it also has a results List, which is a List of campsites that actaully match those filters

Parameters

repo

the CampsiteRepository to fetch campsites from

campsiteOwnerProfileRepo

used in campsite owner mode to find which campsites the user owns

lotteryRepo

used by the date filter to find which campsites have a lottery with that date available

user

the signed in User so that, if it's campsite owner mode, it can show only their campsites

scope

the CoroutineScope that the suspend fetches run in

viewMode

whether this screen is for an entrant or a campsite owner
