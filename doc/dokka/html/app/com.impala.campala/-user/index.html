User

class User

REMEMBER TO CALL initialize()! Represents a user of the site, their permissions, their name (if they set one), and their currently selected role (Owner, Admin, Entrant). Details of the Entrant Profile or Campsite Owner Profile are contained in their own classes and pointed to by User's ID
