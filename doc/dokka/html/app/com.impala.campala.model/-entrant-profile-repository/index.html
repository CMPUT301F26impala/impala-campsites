EntrantProfileRepository

class EntrantProfileRepository

Repository for storing the app's entrant profiles.

Entrant profiles are stored under the same ID as the User they belong to So you can search for an entrant profile with the User ID

Deletion/Banning behaviour is TBD, but what I'm thinking is that we never DELETE the EntrantProfileRecord, we just set hasActiveEntrantProfile to false on the user and then maybe add a flag to prevent it from being displayed in results
