LotteryModel

data class LotteryModel(var campsiteIds: MutableList<String> = mutableListOf(), var lotteryStartTime: Timestamp = Timestamp.now(), var lotteryEndTime: Timestamp = Timestamp.now(), var registrationStartTime: Timestamp = Timestamp.now(), var registrationEndTime: Timestamp = Timestamp.now(), var reservationStartDate: Timestamp = Timestamp.now(), var reservationEndDate: Timestamp = Timestamp.now(), var lotteryCapacity: Int = 0, var entrantIds: MutableList<String> = mutableListOf(), var waitlistCapacity: Int = 0, var numberOfWinners: Int = 1, var waitlistIds: MutableList<String> = mutableListOf(), var winnerIds: MutableList<String> = mutableListOf(), var declinedIds: MutableList<String> = mutableListOf(), var ownerId: String = "", var id: String = Uuid.random().toString())

A lottery for reserving stays at one or more campsites

How the dates work is outlined below

  1. Entrants join form lotteryStartTime and up until lotteryEndTime. At that time winners are drawn // TODO: AT THIS POINT THERE IS NO AUTO-DRAW, JUST A MANUAL OPTION FOR THAT

  2. Winners have from registrationStartTime until registrationEndTime to reserve their campsite dates

  3. The dates they can reserve fall between reservationStartDate and reservationEndDate

If the lottery is full, people go on the waitlist instead. When an entrant leaves, the earliest person on the waitlist gets moved into the lottery.

Parameters

campsiteIds

IDs of the campsites this lottery is for, must have at least one

lotteryStartTime

When the lottery opens

lotteryEndTime

When the lottery closes and winners are drawn

registrationStartTime

When winners can start reserving their dates

registrationEndTime

When winners must have reserved their dates by

reservationStartDate

First day that can be reserved

reservationEndDate

Last day that can be reserved

lotteryCapacity

Max number of entrants in the lottery

entrantIds

IDs of people entered in the lottery

waitlistCapacity

Max number of people on the waitlist

numberOfWinners

Number of possible winners for the lottery, defaults to at least 1 winner

waitlistIds

IDs of people on the waitlist, in the order they joined (earliest first)

winnerIds

IDs of entrants who were drawn as winners, empty until the lottery is drawn

declinedIds

IDs of winners who declined to reserve, they stay in winnerIds so there's still a record of who won

ownerId

ID of the campsite owner who created the lottery
