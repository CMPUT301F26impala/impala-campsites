ReservationModel

data class ReservationModel(val campsiteId: String = "", val ownerId: String = "", val entrantId: String = "", var startDate: Timestamp = Timestamp.now(), var endDate: Timestamp = Timestamp.now(), var hasRating: Boolean = false, val lotteryId: String? = null, var hasBeenCancelled: Boolean = false, val id: String = Uuid.random().toString())

This shares the same User ID as the associated User and EntrantProfile objects, but this tracks specifically the campsite owner details This enables us to disable/ban a campsite owner profile without banning the user as a whole.

Parameters

campsiteId

The ID of the campsite being reserved

The ID of the owner of the campsite being reserved

entrantId

The ID of the entrant making the reservation

startDate

The first date of a reservation

endDate

The last date of the reservation

hasRating

True if there is a rating attached to this reservation

lotteryId

The ID of the lottery that this reservation was created from

id

The ID that the object has in the database
