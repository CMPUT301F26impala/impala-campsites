CampsiteDetailsModel

class CampsiteDetailsModel(val campsiteRepo: CampsiteRepository, val lotteryRepo: LotteryRepository, val campsiteOwnerProfileRepo: CampsiteOwnerProfileRepository, val reservationRepo: ReservationRepository, val user: User, val scope: CoroutineScope) : ObservableModel<CampsiteDetailsModel>

Model for the Campsite Details screen

There will be one of these objects, not one for each campsite The attributes will be updated when a different campsite is displayed
